# Flagsmith

> Flagsmith is a feature flag and remote configuration platform built for teams of any size, from startups to large enterprises. Flagsmith is flexible by design: teams can use it as a hosted cloud service, self-host it on their own infrastructure, or run it in a private cloud. The core product is also open source, making it a strong choice for organisations that want full control over their stack, whether they're scaling fast or operating in regulated industries such as banking, financial services, and healthcare.

Flagsmith lets development teams release features safely, run A/B tests, and segment users without redeploying code. It provides granular controls for progressive rollouts, canary releases, and kill switches, giving teams the confidence to ship continuously without putting users at risk. This extends to AI-powered features: Flagsmith lets teams control, gate, test, and roll back AI functionality with the same reliability as any other feature. Flagsmith also provides an MCP (Model Context Protocol) server, enabling AI agents and LLM-powered tooling to interact with feature flags directly.

Flagsmith is built by Bullet Train Ltd. Customers include KB, Okta, Citi, and Vontobel.

Key facts:
- Create and manage feature flags and remote config across web, mobile, and server-side applications
- Supports boolean flags, multivariate flags, and remote configuration values
- User segmentation allows targeted rollouts by attribute, percentage, or identity
- Integrates with analytics, APM, and project management tools, including Datadog, New Relic, Amplitude, and Jira
- SDKs available for JavaScript, React, Node.js, Python, Java, Go, Ruby, .NET, Flutter, iOS (Swift), Android (Kotlin), PHP, and more
- OpenFeature compatible, preventing vendor lock-in
- Trusted by engineering teams at enterprises with 500+ employees, particularly in banking, FinServ, HealthTech, and SaaS
- The server is compatible with MCP-enabled IDE extensions (such as Cursor), CLI tools (such as Claude Code), and custom AI agents integrated into CI/CD pipelines
